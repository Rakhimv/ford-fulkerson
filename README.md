# Алгоритм Форда-Фалкерсона

Индивидуальное задание по дисциплине «Алгоритмы и анализ сложности».
Рахимов Азизбек, группа 24.Б11, СПбГУ.

Реализация метода Форда-Фалкерсона для задачи о максимальном потоке в двух вариантах:
с поиском увеличивающего пути в глубину (DFS) и в ширину (BFS, алгоритм Эдмондса-Карпа),
генератор тестовых сетей и вычислительные эксперименты.

## Файлы

- `src/maxflow.py` - реализация алгоритма (класс `FlowNetwork`)
- `src/generator.py` - генератор случайных сетей и «плохая» сеть
- `src/experiments.py` - проверка правильности и серии экспериментов A-D
- `src/make_figures.py` - построение графиков
- `results/` - результаты замеров (csv)
- `figures/` - графики

## Запуск

```
pip install -r requirements.txt
python src/experiments.py
python src/make_figures.py
```

Python 3.12. Эксперименты идут несколько минут.
